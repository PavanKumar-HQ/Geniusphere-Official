## 2. Standards for Video Lessons
- Exactly 10 lessons per topic (170 total).
- Verifiable educational YouTube video IDs from credible educators (3Blue1Brown, Karpathy, MIT, Harvard, TED, freeCodeCamp, StatQuest).
- Structured metadata: Title, Summary, Learning Objectives, Key Takeaways, Duration, Channel Title.

## 3. Standards for Interactive Simulation Labs
- Exactly 10 labs per topic (170 total).
- Real mathematical models or state machines.
- Interactive controls (sliders, select dropdowns, toggles).
- Dynamic SVG visualizations reflecting actual calculation state.
- Formative reflection questions and explicit completion criteria.
