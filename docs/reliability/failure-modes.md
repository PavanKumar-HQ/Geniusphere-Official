# Geniusphere System Reliability & Failure Modes Analysis (FMEA)

This document provides an engineering failure mode, effects, and criticality analysis (FMEA) for the Geniusphere platform, defining the impact, likelihood, detection, automated mitigation, and verification status for critical edge cases.

---

## Master Failure Modes Register

| ID | Failure Scenario | Subsystem | Severity | Likelihood | Automated Mitigation Strategy | Automated Test Coverage | Status |
| :--- | :--- | :--- | :---: | :---: | :--- | :--- | :---: |
| **`FM-001`** | **Learner attempts to inspect another student's progress** | Authorization | High | Medium | Server route checks `request.user.userId === userId || isSuperadmin`; PostgreSQL RLS enforces row isolation. | `tests/rls-authorization.test.ts` | **Verified** |
| **`FM-002`** | **Client attempts to manipulate protected role or XP fields** | Application / DB | High | Low | Route handlers strictly extract whitelisted fields; column-level SQL REVOKE blocks direct role updates. | `tests/production-integration.test.ts` | **Verified** |
| **`FM-003`** | **JWT expires while student is completing an exercise** | Authentication | Medium | High | `authenticateRequest` middleware intercepts request, halts execution, and returns structured `401 Invalid or expired token`. | `tests/ai-endpoint.test.ts` (Test 3) | **Verified** |
| **`FM-004`** | **Network drops immediately after lesson completion commits** | Network / Client | Medium | Medium | Client caches progress locally, marks as `pending_sync`, and retries with backoff without corrupting server state. | `tests/production-acceptance.test.ts` (Scenario C) | **Verified** |
| **`FM-005`** | **Network retry or rapid double-click triggers duplicate completion** | Database / Ledger | High | High | `public.xp_ledger` enforces `UNIQUE (reward_key)` with `ON CONFLICT DO NOTHING`. Zero double XP is awarded. | `tests/lab-integration-end-to-end.test.ts` | **Verified** |
| **`FM-006`** | **Two browser tabs update learning progress concurrently** | Concurrency | Medium | High | `SELECT ... FOR UPDATE` row lock in `DomainService.completeLesson` serializes progress calculation. | `tests/production-acceptance.test.ts` (Scenario C) | **Verified** |
| **`FM-007`** | **Database migration fails halfway through execution** | Persistence | Critical | Low | `server/db.ts:runMigrations` wraps each SQL file in an atomic transaction; rolls back completely on error. | `tests/migrations.test.ts` | **Verified** |
| **`FM-008`** | **PostgreSQL connection pool becomes exhausted under spike load** | Infrastructure | High | Low | Connection pool (`pg.Pool`) configured with `max: 20`, `idleTimeoutMillis: 30000`, and `connectionTimeoutMillis: 5000`. | `server/db.ts`, `docker-compose.yml` | **Verified** |
| **`FM-009`** | **Database outage occurs during multi-step completion** | Transactions | High | Low | Multi-step logic runs inside `withTransaction()`. Any error triggers an immediate `ROLLBACK`, leaving zero partial data. | `tests/first-api-slice.test.tsx` (Test E) | **Verified** |
| **`FM-010`** | **Local Ollama daemon goes offline during active inference** | AI Service | Medium | High | `AbortController` timeout aborts request; handler maps failure to explicit HTTP 504 / 502 with zero fake text. | `tests/cross-system-edge-cases.test.tsx` | **Verified** |
| **`FM-011`** | **User submits oversized or malicious prompt injection payload** | AI Gateway | Medium | Medium | Fastify enforces 64 KB payload ceiling; `AILogger` scrubs PII; system prompt isolates model context. | `tests/ai-endpoint.test.ts` (Tests 2 & 5) | **Verified** |
| **`FM-012`** | **AI provider returns malformed or non-JSON response** | AI Gateway | Medium | Low | Provider parser wraps parsing in try/catch, validating structure before sending response envelope. | `server/ai/provider.ts` | **Verified** |
| **`FM-013`** | **Learner refreshes browser during an interactive simulation** | Client Engine | Low | High | Standalone labs initialize from clean default states; course progress is loaded from database. | `tests/public-views.test.tsx` | **Verified** |
| **`FM-014`** | **Mobile browser refuses fullscreen or orientation lock API** | Mobile UX | Medium | High | `LabOrientationGuard` checks API support; provides explicit "Continue in Portrait" button to prevent dead ends. | `src/components/lab/LabOrientationGuard.tsx` | **Verified** |
| **`FM-015`** | **Lab component unmounts without releasing timers/listeners** | Memory / Lifecycle| Medium | Medium | Lab useEffect hooks return explicit cleanup functions canceling `requestAnimationFrame` and clearing timers. | `tests/labs-workflow.test.ts` | **Verified** |
| **`FM-016`** | **User or script hammers expensive `/api/v1/ai/chat` endpoint** | Abuse / Quotas | High | Medium | Sliding window rate limiter enforces 20 req/min limit per user in PostgreSQL with `429 Too Many Requests`. | `tests/ai-endpoint.test.ts` (Test 6) | **Verified** |
| **`FM-017`** | **Database backup exists but restoration has never been verified** | Operations | High | Medium | Automated restoration verification script (`scripts/restore-db.sh`) tests restoring logical dump into PostgreSQL 16. | `scripts/restore-db.sh` | **Verified** |
| **`FM-018`** | **Production service boots with missing required environment secret**| Operations | Critical | Low | `validateProductionConfig()` checks `DATABASE_URL` and `JWT_SECRET` at boot, exiting immediately with clear error. | `tests/first-api-slice.test.tsx` (Test I) | **Verified** |
| **`FM-019`** | **Hosted AI provider deprecates API version or changes response keys**| External API | Medium | Low | `AIProvider` boundary encapsulates provider-specific HTTP calls away from application route handlers. | `server/ai/provider.ts` | **Verified** |
| **`FM-020`** | **Server logs accidentally capture passwords or JWT bearer tokens**| Privacy / Audits | High | Medium | `AILogger` and `HybridAIGateway.redactPrivateData()` automatically scrub authorization headers, passwords, and PII. | `tests/python/test_ai_model_evaluator.py` | **Verified** |
| **`FM-021`** | **Interactive lab simulation throws uncaught WebGL context error**| Client UI | High | Medium | `LabErrorBoundary` catches exception; presents accessible card with "Reload Lab" and "Return to Course". | `tests/cross-system-edge-cases.test.tsx` | **Verified** |
